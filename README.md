# Stock Advisor Pro

A comprehensive financial analysis platform for:
- 300+ NSE Indian Stocks
- 52-Week Analysis with badges
- Forex/Currency Trading (6 INR pairs)
- ETF Trading (5 categories)
- Stock Screener with filters
- Interactive Charts (5 types: Candlestick, Line, Bar, Area, OHLC)
- Expert Recommendations (STRONG BUY/BUY/HOLD/AVOID)
- Professional styling (looks safe, not like a virus!)

## How to Use
1. Open the app URL
2. Select a page from the sidebar
3. Choose a stock or currency pair
4. View analysis and charts!

## Features
- 📊 5 Chart Types
- 📅 Date Range Filtering
- 🏷️ 52-Week Badges
